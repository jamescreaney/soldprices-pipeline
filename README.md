# soldprices-pipeline

HM Land Registry Price Paid Data → bronze / silver / gold on Databricks (Free Edition),
later landed automatically from Azure Storage, with a natural-language query layer
on Azure AI Foundry.

Status: Phase 1 — just started.

- `notebooks/` — Databricks notebooks (PySpark)
- `sql/` — SQL (DDL, checks, gold views)
- `docs/` — design notes and architecture diagram
